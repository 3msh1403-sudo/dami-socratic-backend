# سورس اصلی Amas

فایل‌های این پوشه، نسخه اصلی و دست‌نخورده ماژول‌های Amas هستند که از آرشیو ورودی استخراج شده‌اند.
این فایل‌ها برای حفظ امکان مقایسه و بررسی نگهداری شده‌اند و در اجرای بک‌اند دامی import نمی‌شوند.

نسخه اجرایی دامی در پوشه `src/` قرار دارد. در آن نسخه، جریان اصلی Amas حفظ شده و فقط لایه‌های مدل، Embedding و Vector Database با Gemini و Supabase جایگزین شده‌اند.

هشدار: فایل‌های این پوشه هنوز تنظیمات قبلی Amas مانند Qwen و Chroma را دارند؛ آن‌ها را برای اجرای نسخه دامی استفاده نکنید.
